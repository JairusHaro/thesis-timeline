SAFE LEADER DASHBOARD VERSION

This version keeps your existing Firebase tasks and removes the Delete button from the Leader Dashboard.

Important:
- Uploading these files does NOT erase your existing Firestore tasks.
- The website continues reading the same Firebase collection: tasks
- Existing assigned tasks remain in place.
- The leader can add and edit tasks, but cannot delete them from the dashboard.
- Do NOT delete the Firestore 'tasks' collection in Firebase if you want to preserve your data.

Upload these files to the root of your existing GitHub repository:
- index.html
- leader.html
- style.css
- timeline.js
- leader.js

Replace the old website files and commit the changes.
